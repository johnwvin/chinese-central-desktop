# Dong Chinese character data

`dong.jsonl` is adapted from the Dong Chinese Character Wiki character dump
dated 2025-12-27:

https://data.dong-chinese.com/dump/dictionary_char_2025-12-27.jsonl

Original work: Dong Chinese Character Wiki, https://www.dong-chinese.com/wiki

License: Creative Commons Attribution-ShareAlike 4.0 International,
https://creativecommons.org/licenses/by-sa/4.0/

The adapted file omits images, examples, statistics,
and other unused fields. It retains character glosses, pronunciations, origin
notes, annotated components, and the source's manual-verification flag.
This adapted data is distributed under the same CC BY-SA 4.0 license.
